## 0. 前置与目标

**需要的基础**：一元/多元微积分、线性代数（向量、点积、叉积、矩阵）。

**学完能做到**（验收标准）：

1. 手算圆、圆柱、球、环面的高斯曲率 K 和平均曲率 H，并用代码数值验证；
2. 说明一张曲面在某点的主曲率，并判断两个面在接缝处是 G0/G1/G2；
3. 解释"弦高容差"公式 `h ≈ Rθ²/8`，算出圆柱每圈需要多少段；
4. 看懂 SolidCraft 里 `solid.fillet type: curvature` 为什么只支持直边；
5. 能读 CAD 内核论文里 80% 的几何术语。

**这本书不教**：NURBS 算法、B-rep 数据结构、布尔运算、求交、鲁棒性。那些在
`learning/README.md` 的"下一本"里。

## 3. 六周计划（每天 1–2 小时）

### 第 1 周：曲线
- 读第 1–2 章；做 6–8 道习题（重点：曲率、挠率、Frenet 标架）。
- 改 `curvature_check.rs`：加一个螺旋线 `(a cos t, a sin t, b t)` 的曲率、挠率，和解析值对比。
- **验收**：能说出"圆上 κ=1/R"，并解释为什么直线 κ=0。

### 第 2 周：曲面与例子
- 读第 4–5 章；把球、柱、锥、环面的参数方程各写一遍（不看书画）。
- 在程序里加圆锥 `(u cos v, u sin v, u)`（u 是半径也是高度）。
- **验收**：能写出四种曲面的 `S(u,v)`，并解释 u、v 各自的几何意义。

### 第 3 周：第一基本形式
- 读第 6 章；手算圆柱的 E, F, G（答案：E=r², F=0, G=1）。
- 用程序打印圆柱任意点的 E/F/G，对照。
- **验收**：能手算球面的 E, F, G（答案：E=r²cos²v, F=0, G=r²）。

### 第 4 周：第二基本形式与曲率（重点周）
- 读第 7–8 章；手算圆柱的 L, M, N（按本笔记的符号约定 `II = -S_uu·N`：L=+r, M=0, N=0），推出 K=0、H=1/(2r)。
- 手算球的 K=1/r²、H=1/r（注意符号约定）。
- 跑程序的第 1 部分，确认数值和手算一致。
- **验收**：能手算环面在 v=0 的 K = 1/(r(R+r))、H = (R+2r)/(2r(R+r))。

### 第 5 周：G1/G2 与工程含义
- 跑程序第 2 部分：滚动球圆角在两侧都是 **G1 但非 G2**。
- 解释：环面在接缝处有一个主曲率是 1/f（管方向），圆柱/平面在那里是 0 → 曲率跳变。
- 跑第 3 部分：弦高容差 → 每圈段数。
- **验收**：能向别人解释"为什么滚动球圆角是 G1 而不是 G2"，以及 G2 圆角需要什么。

### 第 6 周：回到仓库
- 用 `solidcraft-cli` 建圆柱 + 倒角，导出 3MF/STL，量一下倒角面的体积，验证它确实是环面。
- 读 `crates/kernel/blend*.rs` 的注释（**只读注释和接口**，别急着读实现）。
- 找到 `solid.fillet` 的 `type: curvature` 说明，理解"only straight edges can be blended"。
- **验收**：写一段 200 字的说明：滚动球圆角、G2 圆角、网格容差三者的关系。

## 4. 三个和仓库结合的实验

### 实验 A：倒角面真的是环面吗？
```bash
# 用仓库构建的 CLI（本机 /usr/bin 的 0.30.1 太旧，数字对不上）
cargo run -p solidcraft-cli --features bundled-render-library -- \
  run /tmp/cyl_fillet.json --out /tmp/a.step
cargo run -p solidcraft-cli --features bundled-render-library -- eval /tmp/cyl_fillet.json
# 或者直接用运行中的 app：控制通道 document.inspect 里的 volume_mm3
```

解析推导（Pappus 定理，截面绕轴旋转）：

```
截面面积   A = f² − πf²/4 = f²(1 − π/4)          （方块减四分之一圆）
切掉体积   V = 2π ∫ r·h(r) dr = 2π[(R − f)·A + f³/6]
```

R=50、f=10 时：A = 21.4602，V = 6440.9 mm³，
所以圆柱 322013.25 − 6440.9 = **315572.35 mm³**。
在 app 里量同一模型应得到约 315572.5——误差 < 0.01%，说明圆角确实是环面的一段。

### 实验 C：G2 圆角为什么只支持直边
```bash
solidcraft-cli commands | grep -A2 "solid.fillet"
# 找到 type: curvature 的说明，再故意在圆柱边上用它：
```
程序会拒绝（"only straight edges can be blended"）。原因是：G2 过渡要求接缝处
**主曲率匹配**，而曲线边（圆）上的主曲率随位置变化，五次的过渡面构造需要沿边
逐点匹配——这是更难的算法（也是内核研究的前沿之一）。

## 5. 常见误区

| 误区 | 纠正 |
|---|---|
| "K=0 就是平面" | 不对。圆柱、圆锥、可展曲面都 K=0，但 H≠0 |
| "G1 就够好了" | 视觉上 G1 有高光断裂；G2 才光滑（汽车/消费电子常用 G2/G3） |
| "H 的符号无所谓" | H 依赖法向取向；不同教材差一个整体负号。K 与取向无关 |
| "曲率越大越弯" | 对曲线成立；对曲面要看主曲率，K=κ₁κ₂ 可能为正、负、零 |
| "网格越密越好" | 密到一定程度后受浮点和显存限制；要按曲率自适应 |

## 附：符号约定

本程序用 `II = -S_uu·N`（即 `II = -dN·dS`），这样凸曲面（球、圆柱外侧）的
平均曲率为正。Pressley 书里对球可能选内法向，得到同样为正的 H——**比较数值时
注意整体符号**，但 K 永远不受影响。

主曲率：κ₁,₂ = H ∓ √(H² − K)，其中 H² ≥ K 恒成立（当且仅当脐点时取等号）。
